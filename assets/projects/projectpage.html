Responsive Personal Portfolio Website

This project is a responsive personal portfolio website designed to showcase my skills and work in a clean, professional way. It is built using HTML and CSS, with a strong focus on responsiveness to ensure it looks great across all devices. The layout follows a minimalist design approach, emphasizing clarity, simplicity, and ease of navigation. Careful use of spacing, typography, and structure helps create a visually appealing and user-friendly experience. Overall, the project demonstrates my ability to design and develop modern, responsive web interfaces.
